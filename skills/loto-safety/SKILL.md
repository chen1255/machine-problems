# 上锁挂牌安全规程技能（loto-safety）

为一次具体检修作业，生成**覆盖全部危险能量、可验证零能量、可挂牌执行**的 LOTO（Lockout/Tagout）作业票。
安全是这套系统的第一优先级：本技能产出的每张作业票，**在交付用户前都要委托 safety-reviewer 子代理独立复核**。

## 触发逻辑

- **触发方式**：作业需要停机、断开能量、开盖伸手、进入电柜、拆卸承压/旋转部件。
- **触发示例**：
  - "要换主轴皮带，怎么断电才安全？"
  - "拆液压卡盘油缸，要不要泄压？"
  - "进电气柜换接触器，LOTO 流程给我一个"
- **不触发**：只是运行中观察、不拆不修 → `fault-triage`；常规保养但不停机拆件 → `pm-planner`。

## CNC 车床必须排查的六类能量源

1. **电能**：主电源隔离开关、控制回路、伺服驱动器、主轴电机；**电容残余电压**（断电后需等待/放电）。
2. **机械惯性能**：主轴、卡盘、刀塔、进给轴、皮带轮停稳前仍有动能。
3. **重力/弹性势能**：垂直轴（Z 轴）、尾座、平衡配重可能下滑；弹簧。
4. **液压能**：液压站、蓄能器、夹紧/回转油缸、管路残余压力。
5. **气压能**：气动卡盘/吹气、三联件、气罐残余压力。
6. **热与化学能**：主轴箱/电机/工件高温、切削液与润滑油接触。

## 工作流程（严格按序）

1. **明确作业范围**：要做什么、拆到什么程度、涉及哪些部件；据此确定需要隔离的能量。
2. **识别能量源与隔离点**：逐一列出能量源、隔离器件（断路器/开关/阀门）的**具体位置编号**、残余能量与释放方式。位置不确定时写"按本机床电气/液压图确认编号"，不编造。
3. **生成 LOTO 作业票**：按标准八步组织（准备通知 → 正常停机 → 隔离 → 上锁挂牌 → 释放残余能量 → 验证零能量 → 作业 → 恢复解锁），并给：
   - **上锁方案**：一人一锁、锁具/挂牌数量、谁持有钥匙；多工种联合作业用多头锁/群组锁箱。
   - **零能量验证**：验电（先在带电体验证验电器有效，再验作业点，最后复验验电器）、压力表回零、**点动/试启动确认无法启动**、等待旋转完全停止、机械支撑垂直轴。
   - **PPE 与资质**：绝缘防护、防砸防割、电气/起重等持证要求。
4. **强制委托 safety-reviewer 复核**：把"设备、作业内容、能量源清单、拟议隔离与验证步骤"发给 safety-reviewer；按其结论增补隔离措施或升级建议，复核结论写入作业票。未过复核的作业票要明确标注"不建议自行处理"。
5. **交付与存档**：用 Write 输出作业票到 `/mnt/user-data/outputs/`（`LOTO作业票_{设备编号}_{作业简述}_{yyyyMMdd}.md`），供打印执行；提醒现场按企业 LOTO 管理制度与作业许可执行。

## 输出格式

使用 `templates/loto_template.md`（作业票）：作业信息 → 人员/许可 → 能量源与隔离点清单表 → 上锁挂牌登记 → 分步隔离与零能量验证（含验证方法）→ 恢复解锁（反序）→ safety-reviewer 复核结论与签字栏。

## 禁止事项

- 禁止只断"停止按钮/控制电"而不断动力电；必须在能量隔离器件上锁，而非操作面板。
- 禁止省略残余能量处理（电容放电、液压/气压泄压、垂直轴支撑、等旋转停稳）。
- 禁止省略零能量验证；"关掉开关"不等于"已无能量"。
- 禁止多人共用一把锁、他人代解锁；一人一锁，作业者本人解除。
- 禁止给"先拆后断电/先拆后泄压"之类捷径；恢复时禁止在人员未撤离、防护未复位前送电。
- 具体隔离开关编号、放电时间、支撑位置无法确定时不编造，标注按本机床图纸/手册确认。
