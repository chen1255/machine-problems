# 故障诊断单（模板）

> 复用本结构生成诊断单。带【】的为占位说明，正式输出时替换；不适用的小节保留标题并注明"无"。

## 〇、安全前提（置顶，不可省略）

- 【一句话点明本次作业的主要危险能量源，如：旋转主轴/卡盘、强电柜、液压残余压力】
- 运行中可做的观察：【哪些排查无需断电】
- 必须先停机断电/泄压才能做的：【哪些检查必须隔离能量、LOTO】
- 【若最终处置含高危步骤，此处注明：已/将委托 safety-reviewer 复核，并在第五节并入其要求】

## 一、设备与现象

| 项 | 内容 |
|---|---|
| 设备编号 / 型号 | 【如 CNC-01 / CK6140】 |
| 数控系统 | 【FANUC 0i-TF / SIEMENS 828D / …】 |
| 故障现象 | 【客观描述看到、听到、读到的现象】 |
| 报警码 / 报警文字 | 【无码写"无报警"；多个码全列】 |
| 发生时机 | 【开机/加工中/换刀时；持续/偶发；频率】 |
| 最近变更 | 【撞机、换料换刀、改程序参数、维修后…】 |
| 历史与恢复方式 | 【是否复发；上次怎么好的】 |

## 二、分诊结论（定性）

- 大类：【机械 / 电气驱动 / 液压气动 / 冷却润滑 / 系统参数程序 / 工艺刀具】（可多选，标主次）
- 判断依据：【一两句现象→大类的推理】
- 历史检索：【machine-db 中同设备工单/同类案例的命中情况；无则写"未检索到历史记录"】

## 四、排查步骤（每步三要素：怎么做 → 如何判定 → 异常去哪）

**步骤 1：【动作】**
- 怎么做：【具体到开关、表计、部位，操作工能照做】
- 判定：【正常现象 / 异常现象，尽量可测量：压力值、温度、间隙、声音】
- 异常则：→ 跳到步骤【N】或转入原因【M】

**步骤 2：【动作】**
- 怎么做：…
- 判定：…
- 异常则：…

> 排序原则：先不用仪器/不拆大件（看、听、摸、查程序参数、互换法），后精密检测/拆解。

## 五、处置建议与升级条件

- 操作工可自行处理：【紧固、补油、复位、改回误改参数等低风险项】
- 须报修/持证处理：【电气、伺服、液压承压、精密间隙调整等】
- 应升级工程师/厂家：【需图纸、PLC、专用诊断仪或反复复发的情形】
- 建议备件/工具：【…】
- safety-reviewer 复核结论（如适用）：【通过 / 补充措施后可进行 / 不建议自行处理 + 必须增补的隔离与资质要求】
- 决策提示：是否停机、拆修、呼叫厂家由现场负责人决定；本单提供利弊与判据，不代决策。
