# 预防性维护计划技能（pm-planner）

把"凭感觉保养"变成**按周期、有标准、能验证、可追溯**的 PM 计划，目标是减少非计划停机、保护精度与寿命。
计划是建议性维护安排，具体周期以机床说明书润滑油表和现场工况为准。

## 触发逻辑

- **触发方式**：要保养/点检/定期维护计划，或问某类保养的周期、方法、判定标准。
- **触发示例**：
  - "给 CNC-01 做一份年度保养计划"
  - "数控车床日常点检表都该有哪些项？"
  - "冷却液多久换、浓度怎么测？"
- **不触发**：保养中发现故障要诊断 → `fault-triage`；为某次停机检修做断电上锁方案 → `loto-safety`。

## 输入要求

| 输入 | 必需 | 缺失处理 |
|---|---|---|
| 设备编号/型号 | 是 | 先查 machine-db `machines`；查不到请用户提供，不凭空编设备 |
| 班次 / 月运行小时 | 否 | 从台账读累计小时与工况；读不到按"两班制、约 350 h/月"估算并标注假设 |
| 数控系统/主要配置 | 否 | 从台账读（带液压卡盘/尾座/排屑器等影响保养项） |
| 计划起止时间 | 否 | 默认从当月起排 12 个月 |

## 工作流程（严格按序）

1. **取台账**：从 machine-db 读 `machines`（型号、系统、投用日期、累计运行小时、配置），作为周期换算依据；并查 `pm_records` 看哪些保养已逾期。
2. **选保养项**：按系统/子系统覆盖：主轴、导轨与丝杠润滑、刀塔、卡盘/尾座、液压站、气动三联件、冷却系统、排屑、电气柜散热与电池、防护与联锁、精度。按工况（加工材料、切削液类型、环境粉尘）增减。
3. **定周期与标准**：每项给周期（可折算成运行小时/班次）、具体方法、**量化判定标准**（油位区间、浓度%、压力 MPa、间隙 mm、温度℃、电池电压等）、所需耗材/工具、安全注意。
4. **分级成表**：日点检 / 周 / 月 / 季 / 半年 / 年，输出计划表；标出"逾期/即将到期"项（结合上次记录）。
5. **安全联动**：凡保养项需进入电柜、接触旋转部件、处理带压液压/高温油液的，给安全提醒；若保养本身演变为停机检修并需要上锁挂牌，转/引用 `loto-safety`，高危方案委托 safety-reviewer。
6. **存档闭环**：计划表用 Write 写到 `/mnt/user-data/outputs/`（`PM计划_{设备编号}_{yyyyMM}.md`）；用户确认实际完成保养后，把记录写入 machine-db `pm_records`（项目、级别、执行人、完成日期、下次到期），形成到期提醒闭环。

## 关键专业要点（不可漏项）

- **绝对编码器电池**：电池低电压会导致参考点丢失，更换通常需在通电规范下进行，周期与操作严格按手册（属于易错且后果重的项，单列提示）。
- **切削液浓度**：用折光仪按品牌系数换算（通常维护浓度 5%–10%，以液厂规定为准），兼顾防锈与皮肤安全；记录 pH/气味/浮油。
- **润滑与液压油**：区分导轨油、液压油牌号，不可混加；油位、油质（乳化/杂质/变色）、泄漏都要查。
- **精度类**：反向间隙、重复定位精度检测需量具与标准，注明由具备条件的人员/计划停机进行。
- **电气柜**：散热风扇/滤网、积尘、防潮；带电柜内部清洁必须断电并由电气人员执行。

## 输出格式

使用 `templates/pm_template.md`：设备与工况假设 → 分级保养计划表（周期/方法/判定标准/耗材/安全）→ 逾期与近期到期提醒 → 12 个月排程概览。

## 禁止事项

- 禁止脱离设备实际配置堆砌通用条目；查不到的设备参数标注"按手册/现场确认"，不编造油品牌号、扭矩、容量。
- 禁止省略电气、旋转、承压、高温相关保养项的安全提醒。
- 禁止把保养周期说成绝对定值；注明受工况影响并以说明书为准。
- 未实际执行的保养不得写入 pm_records 冒充完成（计划与执行记录严格分开）。
