# 报警码解读单（模板）

> 【系统品牌系列】 + 【报警码】 + 【一句话含义】 ｜ 风险等级：【信息 / 警告 / 严重 / 危险】

## 〇、安全前提

- 【该报警处置是否涉及带电检测、轴运动、高压或高温；先给一句醒目提醒】
- 【运行中可做的确认 vs 必须断电后做的检查】

## 一、报警信息

| 项 | 内容 |
|---|---|
| 数控系统 / 系列 | 【FANUC 0i-TF / SIEMENS 840D sl / …】 |
| 报警码 | 【如 414】 |
| 屏幕报警文本 | 【原文照录，含英文】 |
| 报警类别 | 【P/S 程序 / 伺服编码器 / 过热 / 机床厂自定义(1000+) / …】 |
| 出现时机 | 【开机/回零/加工/换刀…；持续/偶发】 |
| 伴随现象 | 【是否掉使能、哪个轴、有无异响异味】 |
| 信息来源 | 【本地库 / 官方手册链接 / 厂家资料 —— 未知则标"待手册核实"】 |

## 二、含义与触发条件

- 含义：【这条报警在**该系统**上的准确含义】
- 触发条件 / 常见原因：【按可能性列出】
  1. 【如：伺服放大器检测到偏差/过载/断线】
  2. 【可结合诊断画面的具体诊断号读取细节，注明路径，如：POS→诊断→200/204】

## 三、风险等级与影响

- 等级：【信息/警告/严重/危险】
- 对设备/加工的影响：【是否掉电、丢位置、可能撞机、是否影响工件/刀具】

## 四、处理步骤（含安全前提）

1. **先做（安全）**：【如：保持急停/断电状态检查，勿盲目复位重试以免扩大故障】
2. 【排查/处理动作：怎么做 → 判定 → 下一步】
3. …
- 需更换/调整：【部件、参数、是否需厂家或持证人员】
- 高危步骤 safety-reviewer 复核（如适用）：【通过/补充措施/不建议自行处理 + 要求】

## 五、复位条件与复位后验证

- 复位方式（单选并明确）：**RESET 软复位即可** / **排除原因后复位** / **需重新手动回零（参考点）** / **断电重启** / **需恢复参数或联系厂家**
- 复位后验证：【低速空运行/单段试切，观察报警是否复现、位置是否正确、尺寸是否正常】
- 若复位后立即复现：【按 fault-triage 进入完整排查，不要反复复位硬开】

> 数据来源与免责：本解读来自【本地报警库 / 标注的手册或链接】。机床厂自定义报警（1000+）与具体参数、诊断号细节请以**本机床随机手册**为准。
