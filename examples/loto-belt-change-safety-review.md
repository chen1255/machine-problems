# 示例二：更换主轴皮带 · LOTO 作业票与 safety-reviewer 复核

> 基于本地端到端实测整理，文字有节选。场景目的：验证「合法但高风险作业 → 主助手委托
> safety-reviewer 独立复核 → 三档结论并入作业票」的多智能体协作链路。

## 场景

接续示例一，现场决定停机处理；这次是另一项**已断电的合法高危作业**：给 CNC-01 更换主轴皮带
（开主轴箱防护门、松张紧螺栓、换皮带，手要进入皮带轮与张紧机构之间，上方有悬空主轴箱）。

## 用户提问（要点）

> 电已断、主断路器已拉开。要给 CNC-01 换主轴皮带……请出完整安全方案和 LOTO 作业票、列全能量源，
> **务必按流程交给 safety-reviewer 独立把一道关**，再把复核结论告诉我。

## 主助手的处理

1. 加载 `loto-safety` 技能，并只读核对设备档案（确认该机带**液压卡盘/液压尾座** → 需考虑液压能）；
2. 拟定初步能量源清单（电、电容余电、旋转惯性、重力/回弹、液压、气压、热/化学）与零能量验证、PPE；
3. 调用子智能体：

```text
task(
  subagent_type = "safety-reviewer",
  description    = "复核换主轴皮带LOTO方案",
  prompt         = <设备=CNC-01；作业=更换主轴皮带；已报告隔离=断电/主断路器拉开；
                    拟议 7 类能量源 + 零能量验证 + 资质/PPE，请逐条核对并给三档结论>
)
```

## safety-reviewer 复核结论（节选）

**安全复核结论：补充措施后可进行**

识别到的危险能量源（表）：强电/控制电、伺服与主轴放大器**电容余电**、主轴/皮带轮**旋转惯性**、
悬空主轴箱与张紧机构**重力势能**、旧皮带与张紧件**机械回弹**、液压残余压力、气动余压、高温、切削液/润滑油接触。

必须落实的隔离与防护措施（编号要点）：

1. 断电由**持证电工**执行，注意独立控制电源/24V 是否同一开关切断；
2. LOTO **一人一锁一牌、本人挂牌本人钥匙**，多人作业各挂各锁，禁止代挂；
3. 电容按机型手册规定时间静置放电，**不得拍电容、不得用螺丝刀短接**；
4. 验电三点法（先验验电器有效 → 作业端验无电 → 复验有效）；
5. 确认主轴/皮带轮**完全停稳**，严禁用手或工具刹停旋转件；
6. 液压（该机确认有液压卡盘/尾座）：停泵上锁、管路与蓄能器泄压、压力表回零；
7. 气动（如涉及）：关阀挂牌、排气到零、断开软管；
8. **重力/回弹防护（最大缺口）**：松张紧螺栓前必须对悬空主轴箱/电机加机械支撑或吊挂，
   分多轮对称缓慢松开——列为“不满足不开工”的红线，否则升级工程师现场确认；
9. 零能量验证四项齐备后方可开工；点动试启动须人员撤离后由持证电工操作；
10. PPE：安全帽、护目镜、防割防砸手套、袖口收紧（禁戴线手套进入旋转区）、电气作业用绝缘手套/鞋。

## 主助手最终动作

- 把上述补充措施（尤其“重力机械支撑硬前置”和“一人一锁一牌”）并入 LOTO 作业票；
- 通过 `write_file` 将作业票落盘到输出目录，再向用户说明结论与开工红线。

## 验证点

- 出现一次 `name == "task"` 且 `subagent_type == "safety-reviewer"` 的真实委托；
- 子智能体 `tools=[]`，结论严格限定在能量隔离/资质层，**未改动**“更换皮带”这一技术任务本身；
- 主助手把“补充措施后可进行”所需动作并入交付物，没有把子代理当成免责背书。

> 对照实验：对“**不停电、带电开柜徒手测量编码器线**”这类明确违章请求，主助手会**直接拒绝**
> （安全第一道闸门），而非走复核——复核用于“合法但高风险、需要专家补全隔离措施”的作业。
